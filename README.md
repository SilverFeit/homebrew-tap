# SilverFeit Homebrew Tap

Official [Homebrew](https://brew.sh) tap for [**MacOS WebCam Controller**](https://github.com/SilverFeit/MacOS-WebCam-Controller) — native macOS Menu Bar UVC webcam hardware controller and CLI (`webcamctl`).

## Install

```bash
brew install --cask SilverFeit/tap/macos-webcam-controller
```

Installs both:
- **`/Applications/WebCam Controller.app`** — Menu Bar popover + `Webcam Settings Panel`
- **`/opt/homebrew/bin/webcamctl`** — Command-line UVC controller (`list`, `describe`, `get`, `set`, `stream`, `preset`, `lock`, `who`, `check-update`)

## Upgrade

```bash
brew upgrade --cask macos-webcam-controller
```

## Uninstall

```bash
brew uninstall --cask macos-webcam-controller
```
